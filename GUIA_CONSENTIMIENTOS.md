# Guía de uso: consentimiento de procedimiento

El formulario vigente permite guardar un consentimiento en pocos pasos: revisa el nombre del cliente, indica el procedimiento y captura las firmas de la persona y del profesional. El nombre profesional y la fecha se completan automáticamente cuando es posible.

Explica verbalmente los riesgos y cuidados específicos antes de solicitar las firmas. Los campos adicionales se encuentran bajo **Agregar detalles al documento (opcional)**. La autorización de tratamiento de datos personales se gestiona por separado. No uses el formato como sustituto de una historia clínica ni de otros requisitos de tu profesión.

Después de guardar, el documento queda asociado al cliente en Stetik. Desde el historial se puede revisar, descargar como HTML para imprimir o eliminar. La exportación incluye las dos firmas capturadas cuando estén disponibles. Para conocer límites y recomendaciones, consulta [CONSENTIMIENTOS_CORREGIDO.md](./CONSENTIMIENTOS_CORREGIDO.md).
